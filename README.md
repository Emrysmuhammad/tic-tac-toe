
# Tic Tac Toe

A simple, modern, two-player Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

Play against a friend on the same device. Take turns placing X and O on the board, and be the first to get three marks in a row to win.

## Features

- Two-player gameplay on the same device
- Automatic player turn switching
- Win and draw detection
- Highlighted winning combinations
- Score tracking for both players
- Reset round without losing the score
- New game option to reset everything
- Responsive design for mobile and desktop
- Accessible buttons and game status announcements
- No external libraries or dependencies

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Git and GitHub

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

### 2. Open the project

Open the project folder in Visual Studio Code.

### 3. Run the game

Open `index.html` in your browser.

Alternatively, install the Live Server extension in VS Code, right-click `index.html`, and select **Open with Live Server**.

## How to Play

1. Player X starts the game.
2. Player O takes the next turn.
3. Continue alternating turns.
4. Get three marks in a horizontal, vertical, or diagonal line to win.
5. If all nine squares are filled without a winner, the round ends in a draw.
6. Select **Reset round** to play again while keeping the score.
7. Select **New game** to reset the board and both scores.
